# Inline Telegram Section Selection

## Goal

Keep section selection in one Telegram message. Selecting or deselecting a section updates the original inline keyboard instead of sending a new “selected sections” message.

## Interaction

- The game-selection response sends one section-selection message and keyboard.
- An unselected section is displayed with its current available marker and label.
- A selected section is displayed with a check mark, for example `🟢 ✅ 22,24`.
- The existing finish button remains in that message and displays the current count as `✅ סיימתי (1)`.
- Pressing a selected section again deselects it and updates the same keyboard.
- Pressing finish with no selected sections keeps the existing validation message.
- Pressing finish with at least one section continues to quantity selection unchanged.

## Implementation

When a `section:*` callback is accepted, the service updates conversation state and calls Telegram's `editMessageReplyMarkup` for the callback message. It does not call `sendMessage` for the selection update. The keyboard continues to be generated by `_buildSectionsKeyboard`, which becomes the single source for selection markers and the finish count.

## Error Handling

Telegram may reject an edit when the markup has not changed or the source message is unavailable. The selected state remains authoritative. Edit failures are contained and logged with a stable, non-secret error code; they do not send a fallback selection message and do not roll back the user's choice.

## Tests

- Selecting a section edits the original message and sends no new selection message.
- The edited keyboard marks selected sections and updates the finish count.
- Deselecting updates the same message and restores the count.
- An edit failure preserves the selection state without sending a fallback message.
- Existing finish, quantity, and confirmation behavior remains unchanged.
